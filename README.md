# Руководство Пользователя

# 1. Введение
# 1.1. Область применения
Регистрация и авторизация в приложении ветеринарной клиники;

Управление заказами услуг/товаров и профилями клиентов (питомцев).

# 1.2. Краткое описание возможностей
Добавление и просмотр заказов на ветуслуги и товары (выбор услуги, назначение даты приёма, добавление товаров в корзину);

Создание и управление карточками питомцев (вид, возраст, история болезней, прививки);

организация и учёт приёмов/лечений (создание визитов, регистрация, ведение истории лечения).

# 1.3. Уровень подготовки пользователя
Владельцы питомцев смогут освоить базовые функции: просмотр услуг, запись на приём, заказ товаров.
Администраторы ветклиники будут использовать расширенный функционал: работа с базой данных (добавление, поиск, обновление, закрытие записей), управление заказами и лечением.

# 1.4. Перечень эксплуатационной документации
руководство пользователя (администратора и клиента).

# 2. Назначение и условия применения
# 2.1. Виды деятельности, функции
Виды деятельности:

просмотр и запись на ветеринарные услуги;

заказ товаров для животных;

ведение медицинской карты питомца;

управление базой данных клиентов/питомцев/заказов (администратор).

Функции:

поддержка пользователей;

загрузка документов (результаты анализов, сканы прививок);

генерация расписания приёма и отчётов по лечению.

# 2.2. Программные и аппаратные требования к системе
Программные требования:

операционная система — Windows 10;

язык программирования — C#;

база данных — Access.

# 3. Состав дистрибутива и запуск
# 3.1. Состав дистрибутива
Основной исполняемый файл приложения (VetClinic.exe для Windows);

Библиотеки, необходимые для функционирования приложения;

Ресурсы (иконки, изображения животных, шаблоны рецептов).

# 3.2. Запуск системы
Убедитесь в соответствии минимальным аппаратным требованиям;

Установите необходимые компоненты (драйверы, .NET Runtime);

Запустите установочный файл (если требуется);

Запустите приложение.

# 3.3. Проверка работоспособности системы
Проверьте корректность отображения списка услуг и товаров;

Убедитесь, что создание заказа работает корректно (выбор услуги, дата, питомец);

Проверьте функциональность поиска в БД администратором (поиск клиента/питомца);

Протестируйте добавление, обновление и закрытие записей в таблицах.

# 4. Описание операций (для администратора и клиента)
# 4.1. Поддержка пользователей (для клиента)
# 4.1.1. Наименование операции: Поддержка клиентов.
# 4.1.2. Условия: Зайти в приложение ветклиники или на сайт.
# 4.1.3. Подготовительные действия: Открыть главную страницу.
# 4.1.4. Основные действия: Найти раздел «Поддержка» или «Помощь», ознакомиться с FAQ, связаться с поддержкой через чат или форму.
# 4.1.5. Заключительные действия: Получить ответ, решить вопрос.
# 4.1.6. Ресурсы: Доступ в интернет, время.

# 4.2. Анализ лечения (для клиента)
# 4.2.1. Название: Просмотр истории лечения питомца.
# 4.2.2. Условия: Быть авторизованным в приложении.
# 4.2.3. Подготовительные действия: Выбрать карточку питомца.
# 4.2.4. Основные действия: Нажать «История лечения», просмотреть назначения, результаты анализов.
# 4.2.5. Заключительные действия: При необходимости скачать или распечатать.
# 4.2.6. Ресурсы: Устройство, интернет.

# 4.3. Регистрация клиента / питомца
# 4.3.1. Наименование: Регистрация нового владельца и питомца.
# 4.3.2. Условия: Открыть главное меню приложения.
# 4.3.3. Подготовительные действия: Выбрать опцию «Регистрация».
# 4.3.4. Основные действия: Ввести данные (ФИО владельца, телефон, адрес; кличка, вид, возраст, вес питомца).
# 4.3.5. Заключительные действия: Подтверждение и создание учётной записи + карточки питомца.
# 4.3.6. Ресурсы: Электронное устройство, интернет.

# 4.4. Регистрация на приём (для клиента)
# 4.4.1. Название: Запись на ветеринарный приём.
# 4.4.2. Условия: Быть авторизованным.
# 4.4.3. Подготовительные действия: Открыть раздел «Услуги».
# 4.4.4. Основные действия: Выбрать услугу, врача, дату и время, нажать «Записаться».
# 4.4.5. Заключительные действия: Получить подтверждение записи.
# 4.4.6. Ресурсы: Интернет-соединение.

# 4.5. Авторизация (клиент / администратор)
# 4.5.1. Название: Вход в систему.
# 4.5.2. Условия: Запустить приложение ветклиники.
# 4.5.3. Подготовительные действия: Открыть главную страницу.
# 4.5.4. Основные действия: Нажать «Войти», ввести логин/пароль.
# 4.5.5. Заключительные действия: Получить доступ к роли (клиент или администратор).
# 4.5.6. Ресурсы: Интернет.

# 5. Операции администратора с базой данных
Администратор может выполнять следующие действия с таблицами БД (например: Клиенты, Питомцы, Услуги, Заказы, Приёмы):

# 5.1. Добавление в таблицу
Нажать кнопку «Добавить запись»;

Заполнить поля (например: новый клиент, новая услуга, новый приём);

Сохранить.

# 5.2. Найти в таблице
В поле поиска ввести значение (кличка питомца, фамилия клиента, ID заказа);

Нажать «Найти» — система отфильтрует записи.

# 5.3. Обновить таблицу
Выбрать существующую запись;

Изменить нужные поля (изменить дату приёма, добавить диагноз);

Нажать «Обновить» / «Сохранить».

# 5.4. Закрыть таблицу (завершить работу с БД)
Нажать кнопку «Закрыть» в окне просмотра таблицы;

При необходимости сохранить изменения перед закрытием.

# 6. Аварийные ситуации
Сбой в электроснабжении;

Отключение интернета (невозможность онлайн-записи);

Сбой в работе сервера БД;

Потеря данных о заказах, приёмах или карточках питомцев (рекомендуется резервное копирование).

# 7. Рекомендации по освоению
Изучить основные элементы интерфейса: список услуг, каталог товаров, личный кабинет, карточка питомца;

Пользователь должен обладать базовыми навыками работы с компьютером;

Уметь входить в учётную запись и выходить из неё;

Понимать, как выбрать услугу, записать питомца на приём, оплатить заказ онлайн;

Администратору — освоить работу с БД (добавление, поиск, обновление, закрытие таблиц).
